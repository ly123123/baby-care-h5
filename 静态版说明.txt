宝宝成长记 · 静态 PWA 版（v1.4.0）

1. 把本文件夹整个上传到 Cloudflare Pages / GitHub Pages 等 HTTPS 静态托管。
2. iPhone Safari 打开分配到的 https:// 地址。
3. 分享 → 添加到主屏幕 → 宝宝成长记。
4. 打开一次等几秒，让离线缓存装好；之后断网也能用。
5. 数据只保存在这台手机的浏览器里，不会上传；请定期在 App「我的」里导出备份。
6. 本静态版没有家庭实时共享功能；需要家人共享请使用带 server 的完整版。
7. 今日页右上角「纸质记录」支持拍照 + 本机 PaddleOCR；首次识别需下载约 60MB 模型，之后可离线识别。
